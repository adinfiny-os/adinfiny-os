### Architecture & Core Stack

- **On-Device Intelligence:** Local LLM/SLM orchestration optimized for mobile NPUs (Qualcomm Snapdragon / ARM).
- **Native UI & System Layer:** Built with Kotlin, Jetpack Compose, and Clean Architecture for ultra-low latency interactions.
- **Broader Adinfiny Ecosystem:** Part of the **[Adinfiny](https://adinfiny.com)** technology stack alongside **Orbis** (3D spatial web engine in Three.js), **City Adinfiny 2.0** (multi-agent simulation in Unity 6.5), and **Adinfiny Quant**.
